Entry for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) — a blind-judged contest to write the funniest one-line office joke, under 200 characters. The program writes the entry to `entry.txt` and enforces the gate (single non-blank line, 1–199 characters) before writing.

> I asked for a raise and they gave me a pizza party — turns out my salary is now paid in pepperoni.

## Run it

```bash
node main.ts
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
